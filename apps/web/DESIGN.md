# OptiTrace console design

An operations workspace for seeing exactly why a verification stopped. Navy navigation (#183252), cool slate canvas (#f3f6fa), white working surfaces, blue actions (#2967d5), teal successful evidence (#187d78), and amber unresolved evidence (#956019). Segoe UI provides legible Windows-native sans typography; compact numerical details use tabular figures.

The signature visual is a horizontal execution rail: three labelled capability nodes expose compulsory work, observed results, and skipped calls. Forms and a trace inspector sit side by side; tables own the remaining views. Left aligned content, generous working space, quiet dividers, no decorative metrics or gradients. On narrow screens navigation becomes horizontal and the execution rail stacks.

Review: this is a verification workbench rather than a card dashboard. Every metric comes from an API response and all costs remain labelled synthetic. Keyboard focus, explicit input labels, status text, reduced-motion support, and readable empty/error states are required.
